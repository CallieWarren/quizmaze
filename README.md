# QuizMaze

QuizMaze is a mobile learning game that turns studying into an interactive adventure. Instead of using traditional flashcards alone, QuizMaze combines quiz-based review with maze exploration to make learning more engaging, rewarding, and fun.

In Quiz Mode, you review digital flashcards and test your knowledge one card at a time. Each correct answer earns swipes, which can then be used in Maze Mode to reveal paths, explore the maze, and make progress through the game. This creates a simple but motivating loop: the more you learn, the more you can play.

The app is also built with flexibility in mind. QuizMaze can support many different subjects, making it useful for vocabulary practice, memorization, concept review, and other study activities. With AI-assisted flashcard generation, users can also create learning content more easily and explore new topics with less setup time.
